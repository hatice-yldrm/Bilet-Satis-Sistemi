# Bilet Satış Sistemi

Etkinlikler için bilet satışı yapılan web uygulaması.

## Özellikler
- Etkinlikleri listeleme ve filtreleme
- Koltuk seçimi ve bilet satın alma
- Kayıt ol / giriş yap
- İletişim formu

## Kullanılan Teknolojiler
- HTML, CSS, JavaScript
- Node.js, Express
- Microsoft SQL Server
